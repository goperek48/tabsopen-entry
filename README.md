How many tabs do you have open? **137** — one number, digits only.

`main.py` writes the honest count of open browser tabs to
`/output/entry.txt`. The count is a real, lived-in number: research tabs
for half-finished projects, docs left open just in case, and years of
"I'll read this later" that never got closed. Specific, not round — a
count someone actually has, not a number picked to shock.
